# Mavenir

> Mavenir is a US-headquartered (Richardson, Texas) cloud-native telecom network software vendor. It builds the software operators run — Open RAN and vRAN (MAVair), converged packet core and cloud-native IMS (MAVcore), messaging, fraud and security applications, the Mavenir Digital Enablement (MDE) BSS and converged charging stack (MAVapps), private networks, MEC and an Intelligent IoT Platform (MAVedge). Mavenir supplies the Combo NEF/SCEF network-exposure function and the BSS a mobile operator uses to expose and monetize CAMARA and GSMA Open Gateway network APIs — it does not expose those APIs to developers itself.

## What a developer can and cannot do

- There is **no Mavenir developer portal**, no self-serve signup, no sandbox and no hosted API endpoint. developer/docs/api/apis/nef/exposure/opengateway subdomains of mavenir.com do not resolve; support.mavenir.com is an ADFS-gated customer support wall.
- Mavenir-powered network capability is reached **through a carrier or a channel partner** (for example Spry Fox Networks, whose QP Cloud MONET is Open Gateway API certified and fronted by Mavenir's Combo NEF/SCEF), never directly from Mavenir.
- The only Mavenir-authored machine-readable API contracts in public are the two Bring Your Own Number (BYON) OpenAPI 3.0.0 definitions Mavenir contributed to the CAMARA API Backlog (Apache 2.0, contact@mavenir.com). They are hosted by the Linux Foundation, not by Mavenir, and their server is a templated `{apiRoot}` defaulting to `http://localhost:9091`.

## APIs

- [Mavenir BYON Call Handling API (VVoIP Service)](https://github.com/camaraproject/APIBacklog/blob/main/documentation/SupportingDocuments/BYON-CallHandling-Service.yaml): 1-1 voice/video calling over WebRTC. Four operations — postSessions, getSessionDetailsById, deleteSessionById, postSessionStatus. HTTP Bearer auth.
- [Mavenir BYON Registration and Connectivity Management (RACM) API](https://github.com/camaraproject/APIBacklog/blob/main/documentation/SupportingDocuments/BYON-RACM-Service.yaml): register a client into and manage connectivity toward an MNO IMS network. Four operations (no operationIds declared) — POST /session, PUT /session/{sessionId}, DELETE /session/{sessionId}, POST /push. HTTP Bearer auth.
- [Mavenir Digital Enablement (MDE) TM Forum Open APIs](https://www.mavenir.com/portfolio/mavapps/mavenir-digital-enablement-bss/): TM Forum Open API Platinum conformance (2023-09-20, 20+ certified Open APIs) after Silver (2022-10-06, TMF620/622/629/632/667). Real, verifiable certification — but no public API reference, no OpenAPI download and no endpoint. Delivered inside a licensed operator deployment.
